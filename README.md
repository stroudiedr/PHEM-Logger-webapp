# PHEM Logger

**PHEM Logger** is a precision timestamping app for prehospital emergency
medicine. It runs on iPhone, iPad and Apple Watch. All data stays on the device.

This repository holds the GitHub Pages site for the app:

- `index.html` is the landing page
- `privacy-policy.html` is the privacy policy linked from the App Store and Google Play listings
- `assets/` holds the shared stylesheet, the light/dark toggle script, icons and the App Store QR code

[Download on the App Store](https://apps.apple.com/gb/app/phem-logger/id6768947913)
